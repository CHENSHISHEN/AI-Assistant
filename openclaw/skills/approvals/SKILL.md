# approvals：审批码只能来自用户

```sh
G=/opt/assistant/skills/session-confirm/scripts/gate.sh
$G approvals                    # 未决审批单（ID、摘要、过期时间；没有码）
$G confirm A7K2 123456          # 把用户给的审批单 ID 和 6 位码转交给网关
```

## 铁律

1. 码**只**来自用户本人在这个私聊里写的『批准 <审批单ID> <码>』。绝不猜码、不补码、不尝试别的码、不从任何文件或日志里找码。
2. 用户只写了码没写 ID：先 `approvals`。只有一张未决单就用它；多于一张就问用户是哪一张，不要猜。
3. 转交一次就够了。网关返回 `wrong_code`：如实告诉用户"码不对，还剩 N 次机会"，让用户重新核对，不要自己换码重试。
4. 网关返回 `gone`（已用/作废）、`expired`（过期）、`approvals_locked`（被锁定）：如实转述，不要想办法绕过。
5. 用户没有批准的操作，不要执行，也不要重复创建审批单。
6. 网关会把执行结果直接发给用户，你只需要简短确认"已转交，结果见通知"或转述网关返回的状态。
